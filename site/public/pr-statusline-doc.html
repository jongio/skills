Copilot CLI Statusline Extensions

Composable terminal statuslines for GitHub Copilot CLI: Pull Requests (pr-statusline), GitHub Issues (issue-statusline), and Subagents (subagent-statusline). Run them individually or compose all three side-by-side on a single row via ~/.copilot/statusline-compose.mjs.

Installation

Recommended

Install via Copilot Plugin Marketplace

Add the marketplace once in Copilot CLI, install the jongio-skills plugin, and pick which statuslines (Pull Requests, GitHub Issues, and Subagents) you want enabled:

Step 1 · Add the marketplace (one-time setup in Copilot CLI)
/plugin marketplace add jongio/skills
Step 2 · Install all skills & statuslines in Copilot CLI
/plugin install jongio-skills@jongio-skills
Step 3 · Pick your statuslines anytime in Copilot CLI
/statusline-setup
Alternative: Standalone Statusline Scripts (Install only the statuslines without the skills plugin)

Windows (PowerShell one-liner)

irm https://raw.githubusercontent.com/jongio/skills/main/install-statusline.ps1 | iex

macOS & Linux (Bash one-liner)

curl -fsSL https://raw.githubusercontent.com/jongio/skills/main/install-statusline.sh | bash

Annotated Visual Guide: Each Statusline in Isolation

1. Pull Request Statusline (extensions/pr-statusline)

Tracks every pull request the active session is working on across repositories and worktrees. The annotated infographic below shows all four status states and every icon inside a PR pill:

Click to view full size
Clickable Repo#PR Link OSC 8 terminal hyperlink to owner/repo#number on GitHub (Ctrl+Click or Cmd+Click).
CI Checks (Passed / Total) Shows passing vs total checks with checkmark (all pass), hourglass (running), or X (failing).
Merge Conflict Alert Warning icon shown when mergeStateStatus === "DIRTY".
Approvals (Approved / Total) Thumbs-up icon with approvals received vs total reviewers.
Review Threads (Resolved / Total) Comment icon with resolved threads vs total review threads.
Purple Merged Badge Turns GitHub Merged Purple when landed and auto-dismisses on your next prompt.

2. GitHub Issue Statusline (extensions/issue-statusline)

Renders a separate clickable pill for each GitHub issue the active session is working on. The annotated infographic below shows all four issue states and every icon inside an issue pill:

Click to view full size
Separate Issue Pill & Link Each tracked issue gets its own pill and clickable OSC 8 link (issue icon or bug icon).
Priority / Category Label Surfaces top priority or category labels (P0, P1, bug, enhancement).
Linked Open PR Indicator Displays a PR branch icon when an open pull request references or closes the issue.
Assignee Handle Shows the assigned GitHub user (green when assigned + active, amber when unassigned).
Comment Count Displays total discussion comments on the issue.
Purple Closed Badge Turns purple when closed as completed during this session and auto-dismisses on your next prompt.

3. Subagent Statusline (extensions/subagent-statusline)

Tracks active session subagent counts across starting, in PR, merged, and failed. The annotated infographic below explains each counter and status transition:

Click to view full size
Subagent Fleet Icon Click opens subagent PRs in your browser; run /tasks in console to inspect background subagents.
Starting Counter Number of session subagents actively working before opening a pull request.
In-PR Counter Number of session subagents with an open pull request under review or CI.
Merged Counter Number of session subagents whose pull requests have merged.
Failed Counter Shown in red if any session subagent exits with an error.
Purple All-Merged Pill When all subagent PRs merge (0 starting, 0 in PR), the pill turns purple and auto-dismisses on your next prompt.
